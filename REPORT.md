## 2. Відповідь на контрольне запитання

**Запитання:** Які переваги використання raw-рядків (`r""`) при роботі з регулярними виразами?

**Відповідь:**

Головна перевага сирих рядків (raw-strings, позначаються префіксом `r` перед лапками, наприклад `r"pattern"`) полягає в тому, що **вони відключають стандартну обробку екранування символів зворотного слешу (`\`) інтерпретатором Python**.

У звичайних рядках Python зворотний слеш слугує керівним символом (escape character) для позначення спеціальних сутностей, таких як перенесення рядка `\n`, табуляція `\t` тощо. У той самий час синтаксис регулярних виразів сам активно використовує зворотний слеш для позначення метасимволів: `\d` (цифра), `\w` (слово/символ), `\s` (пробіл), `\b` (межа слова).

Якщо не використовувати `r""`:
1. Виникає проблема **подвійного екранування**: щоб передати один зворотний слеш у рушій регулярних виразів, у звичайному рядку доводиться писати подвійний слеш `\\`.
2. Щоб знайти звичайний фізичний символ зворотного слешу в тексті, у звичайному рядку доведеться написати чотири слеші: `"\\\\"` (два слеші з'їдає інтерпретатор Python, залишаючи два, які потім передаються в рушій `re`).
3. Використовуючи raw-рядок, цей самий шаблон записується значно чистіше: `r"\\"`.

**Порівняльний приклад:**
```python
# Без raw-рядка (громіздко, погіршує читабельність, ризик SyntaxWarning):
pattern_normal = "\\b[A-Z]{2}-\\d{4}\\b"

# З raw-рядком (чистий, стандартний вигляд регулярного виразу):
pattern_raw = r"\b[A-Z]{2}-\d{4}\b"
